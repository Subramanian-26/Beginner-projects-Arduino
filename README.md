## Overview

This repository includes hands-on projects covering sensors, LED control, motor operation, robotics, and more. Each project folder contains an Arduino sketch (.ino file) demonstrating fundamental electronics and programming concepts.

## Project Categories

- **LED Control**: Blinking LED, Dimmable LED, RGB Colors, Traffic Light
- **Sensors**: PIR Sensor, Temperature Sensor, Tilt Sensor
- **Input Devices**: Push Button Switch, Potentiometer
- **Output Control**: Active Buzzer, DC Motor, Servo
- **Advanced**: IR Remote Control, RGB Input, Servo Temperature Display
- **Logic**: Binary Counter

## Getting Started

1. Open the project folder you want to explore
2. Review the sketch file (.ino)
3. Upload the code to your Arduino board using Arduino IDE
4. Connect components according to the circuit requirements
5. Test and modify as needed
